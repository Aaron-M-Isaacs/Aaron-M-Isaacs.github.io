## Context
When I first got to high school, there was a class called robotics. I knew practically nothing about it, at the time I joined it because for some reason I wanted to make a crossbow. My junior-high brain thought it would be cool. At first I was disappointed, not only had I learned that creating something that qualified as a weapon was against school policy (go figure), but it seemed as though I wouldn't get to create whatever robot I wanted either. What I had learned was that the class was dedicated for a program called Vex Robotics, a program where kids can learn to build robots, in a competition format to get kids interested in STEM. Over time, I eventually grew to love it.

## Problem
The main problem was that robots need to be programmed. But on my team (of 2 people) no one knew how to program a robot. To be fair, no one in the Freshman class knew how to program. The most anyone had done was drag and drop block programming on Scratch. 
## Approach
Lucky for me in robotics they had a program for just that. So that's how it started, I was learning to use programming using drag and drop blocks. It worked well for a few months, and then eventually I started to run into issues, some of the things I wanted to program weren't available in drag and drop blocks. I eventually figured out how to do what I wanted, but it took plenty of clever thinking to get there.

End of year 1 came around, and the competition game for the next year had already been announced. I was already starting to think I needed to up my programming game, after all, I want to be able to start doing some of the more complex things in programming and several of my friends had already started on RobotC (the *other* coding software for Vex Robotics, which used C programming instead of drag and drop blocks). Not to mention, I might want to do this programming thing as a job after school so who knows, might be good to learn an actual language.

That summer I had learned C++, not really knowing the difference between C and C++. Later I eventually learned it more or less is because C++ allows for object-oriented programming, which I was not utilizing in robotics anyway, so it didn't really matter.


## Outcome
After taking some online courses in the summer to learn C++, I had started to use it more and more in the classroom on RobotC. Other members of my class had learned much of their programming for older classmates, but I had learned it from online courses, which I had later learned gave me an advantage.

I had started programming functions into my code for the autonomous portion of the competition. Something I later realized that other students were not leveraging. Who knew that learning something as simple as functions would give me an edge in a robot competition. Anyways, over the years I had become one of the well known programmers, eventually teaching lower grades coding techniques such as functions and the like. It had taught me that I loved programming, and even though I pursued a different degree in college, I still loved it enough that I at least wanted to get a minor in it.

Eventually through my minor classes, I realized that I enjoyed it more than my major classes. Though due to various scheduling conflicts, I hand't taken most of my minor classes until I was already a Senior in college. I enjoyed my major, but I enjoyed programming more. So as soon as I graduated, I made a career change. And I am so happy that I did.
