## Context
After being in the industry for a few years I had decided it was long overdue that I set up my own web portfolio. Most software engineers have them, so where was mine? I need to show potential employers *something* after all.

## Problem
Most of my work has to do with backend work: data manipulation, ETL or ELT pipelines, status codes, API calls, concurrency, error handling, etc. Very little of my work has actually been front-end worthy, even though most of my starting experience you *could* say I was a full-stack software engineer, the front-end portion of the work was primarily Streamlit. 

Streamlit is really nice for small web-apps, it handles 90% of the front-end work for you, allowing you to focus on the backend work. But most of my work has been in Python, which is not known as a front-end programming language. So there were two issues before I began working on my portfolio, one being that my typescript experience was rather limited, and the other being that my only front-end experience was with Streamlit.

## Approach
At first, I made a streamlit app as my portfolio. It was fine, not flashy, maybe a little boring for a portfolio. I had utilized Streamlit's platform for hosting the application, but it would pause displaying my app if it got no views, making the user to click a button to "bring it back up", which wasn't a good look for a portfolio. So I opted for a new approach: to build an app using Astro, and to leverage GitHub Pages.

You may call it cheating, but I had Claude's Opus model start the website. At the time of creation, a month-long individual subscription to Claude was $20 and gives you access to Claude Code, which allowed me to feed the model just the right amount of information to start the portfolio. However, ever since then, everything has been done by hand. The repository is public, if you'd like to go see for yourself. 

## Outcome
Every feature, every nitpick, every new addition or deletion from this website since the foundation was laid, has been done by me. I'm not completely new to Typescript, so it hasn't been as great a challenge as it would have been starting from the ground up, but the goal was more to keep practicing in Typescript rather than diving into HTML and CSS, and I feel as though that I am successfully accomplishing that goal.
